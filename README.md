# Nusa Wear — E-commerce Fashion

## Deskripsi Project
Nusa Wear adalah website e-commerce pakaian kasual yang menyediakan katalog produk dengan desain simpel dan nyaman untuk aktivitas sehari-hari.

Project ini dibuat untuk memenuhi Ujian Tengah Semester (UTS) mata kuliah Rekayasa Web.

## Fitur Website
- Katalog produk pakaian.
- Pencarian produk berdasarkan nama atau kategori.
- Filter produk berdasarkan kategori.
- Halaman detail produk.
- Halaman Tentang Nusa Wear.
- Database MySQL untuk menyimpan data produk.
- Tampilan responsif menggunakan Bootstrap.

## Teknologi
- Laravel 13
- PHP
- MySQL
- Blade Template
- Bootstrap 5
- HTML, CSS, dan JavaScript

## Struktur Project
- `app/` — model dan controller.
- `database/` — migration dan seeder.
- `public/assets/images/` — gambar produk.
- `resources/views/ecommerce/` — halaman katalog, detail, dan tentang.
- `routes/web.php` — konfigurasi rute website.
